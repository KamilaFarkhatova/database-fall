Lab 04 — First SQL Query

==================================================
1. CREATE TABLE
==================================================

Command:

CREATE TABLE students (
    student_id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(150),
    faculty VARCHAR(100)
);

Result:

CREATE TABLE
