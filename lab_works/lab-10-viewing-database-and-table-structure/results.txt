3. View the structure of customers
============================================================

Command:
postgres=# \d customers

Output:
                                              Table "public.customers"
      Column       |          Type          | Collation | Nullable |                    Default
-------------------+------------------------+-----------+----------+------------------------------------------------
 customer_id       | integer                |           | not null | nextval('customers_customer_id_seq'::regclass)
 full_name         | character varying(100) |           |          |
 city              | character varying(50)  |           |          |
 registration_date | date                   |           |          |
Indexes:
    "customers_pkey" PRIMARY KEY, btree (customer_id)
Referenced by:
    TABLE "orders" CONSTRAINT "orders_customer_id_fkey" FOREIGN KEY (customer_id) REFERENCES customers(customer_id)

Result:
The customer_id column is the primary key.
The orders table references customers through customer_id.

5. View the structure of orders
============================================================

Output:
                                         Table "public.orders"
    Column    |          Type          | Collation | Nullable |                 Default
--------------+-------------------------+-----------+----------+------------------------------------------
 order_id     | integer                 |           | not null | nextval('orders_order_id_seq'::regclass)

 status       | character varying(20)   |           |          |

    "orders_pkey" PRIMARY KEY, btree (order_id)

    "orders_customer_id_fkey" FOREIGN KEY (customer_id) REFERENCES customers(customer_id)

8. View the structure of users
============================================================

Command:
postgres=# \d users

Output:
                                         Table "public.users"
   Column   |            Type             | Collation | Nullable |              Default
------------+-----------------------------+-----------+----------+-----------------------------------
 id         | integer                     |           | not null | nextval('users_id_seq'::regclass)
 first_name | text                        |           |          |
 last_name  | text                        |           |          |
 email      | text                        |           |          |
 created_at | timestamp without time zone |           |          | now()
Indexes:
    "users_pkey" PRIMARY KEY, btree (id)
    "idx_users_email_unique" UNIQUE, btree (email)
    "idx_users_last_first" btree (last_name, first_name)

Result:
The id column is the primary key.
A unique index exists on email.
Another index covers last_name and first_name.
