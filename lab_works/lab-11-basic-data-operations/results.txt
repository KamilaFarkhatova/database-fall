Lab 11 — Basic Data Operations

============================================================
1. Create Students_lab11 table
============================================================

Command:
CREATE TABLE Students_lab11 (
    student_id SERIAL PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    birth_date DATE
);

Output:
CREATE TABLE

============================================================
2. Insert one student
============================================================

Command:
INSERT INTO Students_lab11 (first_name, last_name, birth_date)

5. Update Erbol's birth date
============================================================

Command:
UPDATE Students_lab11
SET birth_date = '2006-12-25'

Command:
SELECT * FROM Students_lab11;

(4 rows)

============================================================
6. Delete Jibek
============================================================

Command:
DELETE FROM Students_lab11
WHERE first_name = 'Jibek' AND last_name = 'Karimova';

Output:

============================================================
7. Delete students born before 2006-01-01
============================================================

Command:
DELETE FROM Students_lab11
WHERE birth_date < '2006-01-01';

Output:
DELETE 0

No records matched the condition.

============================================================

UPDATE Students_lab11
