Data Import/Export and Backup
Lab Results
==============================

1. COPY COMMAND
---------------

Export employees:

COPY employees TO '/tmp/employees.csv' WITH CSV HEADER;

Output:
COPY 5

Import employees:

COPY employees FROM '/tmp/employees.csv' WITH CSV HEADER;

Output:
COPY 5

Custom delimiter export:

COPY employees TO '/tmp/employees.txt'
WITH DELIMITER '|' NULL 'N/A' CSV HEADER;

Output:
COPY 5

Import selected columns:

COPY employees(first_name, last_name, email)
FROM '/tmp/new_employees.csv' WITH CSV HEADER;

Output:
COPY 3

Export IT employees:

COPY (SELECT * FROM employees WHERE department = 'IT')
TO '/tmp/it_employees.csv' WITH CSV HEADER;

3. PG_DUMP AND PG_RESTORE
-------------------------

The commands are executed in the operating-system terminal.

Backup commands:
- backup.sql — SQL-format backup
- backup.dump — custom-format backup
- tables_backup.sql — selected-table backup
- backup_verbose.dump — custom-format backup with verbose output
- schema_only.sql — schema-only backup
- data_only.sql — data-only backup
- backup_without_logs.sql — backup excluding log_table and temp_data


4. FULL DATABASE BACKUPS
------------------------

The backup commands create the requested files:
- full_cluster_backup.sql
- full_production_backup.dump
- backup_with_ownership.dump

The retention command removes matching backup files older than seven days.

7. DATA MIGRATION STRATEGIES
----------------------------

Create staging table:

CREATE TABLE staging_customers AS
SELECT * FROM customers WHERE 1=0;

Output:

SELECT 0

Extract customers:

COPY (SELECT * FROM customers LIMIT 10000 OFFSET 0)
TO '/tmp/customers_batch_1.csv' WITH CSV HEADER;

Output:

COPY 3

Load staging table:

COPY staging_customers
FROM '/tmp/customers_batch_1.csv' WITH CSV HEADER;

Output:

COPY 3

Merge data:

INSERT INTO target_customers
SELECT * FROM staging_customers
ON CONFLICT (customer_id) DO UPDATE SET
    first_name = EXCLUDED.first_name,
    last_name = EXCLUDED.last_name,
    email = EXCLUDED.email;

Output:

INSERT 0 3
