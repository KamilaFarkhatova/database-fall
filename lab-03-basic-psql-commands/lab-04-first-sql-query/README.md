# Lab 04 — First SQL Query

## Objective

Practice basic SQL syntax and execute the first SQL queries in PostgreSQL.

## Topics

- SQL syntax basics
- SELECT statement
- FROM clause
- WHERE clause
- ORDER BY clause
- LIMIT clause
- SQL comments

## Queries

The laboratory demonstrates how to:

- retrieve all columns and rows from a table;
- select specific columns;
- filter rows using WHERE;
- sort query results using ORDER BY;
- limit the number of returned rows using LIMIT;
- use single-line and multi-line SQL comments.

## Files

- `first_sql_query.sql` — SQL queries executed during the laboratory.
- `results.txt` — PostgreSQL output from the executed queries.
- `README.md` — description of the laboratory.
