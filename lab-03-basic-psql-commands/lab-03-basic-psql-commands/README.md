# Lab 03 — Basic psql Commands

## Objective

Practice basic PostgreSQL `psql` commands and SQL operations.

## Topics

- Connecting to PostgreSQL
- Listing databases with `\l`
- Connecting to a database with `\c`
- Listing tables with `\dt`
- Listing relations with `\d`
- Describing table structure with `\d students`
- SQL help with `\h`
- psql meta-command help with `\?`
- Exiting psql with `\q`

## SQL Operations

- `CREATE TABLE`
- `INSERT INTO`
- `SELECT`
- `DROP TABLE`

## Files

- `basic_psql_commands.sql` — commands executed during the laboratory.
- `results.txt` — PostgreSQL output.
- `README.md` — description of the laboratory.
