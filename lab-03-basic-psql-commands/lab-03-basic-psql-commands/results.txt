Lab 03 — Basic psql Commands

1. Connection

Command:
psql -h localhost -p 5432 -U postgres -d postgres

Result:
Successfully connected to PostgreSQL database "postgres" as user "postgres".

6. Create students table

Command:

CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    age INT
);

Result:
CREATE TABLE

8. Describe students table

Command:
\d students

Result:

                                    Table "public.students"

 Column |          Type          | Collation | Nullable |              Default
--------+------------------------+-----------+----------+--------------------------------------
 id     | integer               |           | not null | nextval('students_id_seq'::regclass)
 name   | character varying(100) |           |          |
 age    | integer               |           |          |
Indexes:
    "students_pkey" PRIMARY KEY, btree (id)


9. Insert data

Command:

INSERT INTO students (name, age)
VALUES ('Alice', 21), ('Bob', 23);

Result:
INSERT 0 2


10. Select data

Command:
SELECT * FROM students;

Result:

 id | name  | age
----+-------+-----
  1 | Alice |  21
  2 | Bob   |  23
(2 rows)


11. SQL command help

Command:
\h

Result:
PostgreSQL SQL command help was displayed successfully.


12. psql meta-command help

Command:
\?

Result:
The psql meta-command help was displayed successfully.


13. Drop students table

Command:
DROP TABLE students;

Result:
DROP TABLE
